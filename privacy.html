最終更新：2026年10月27日

このページは、「そらゆめ さとがえり ツール」（コメント返信ツール・アナリティクスの取得・Cメール。以下「本ツール」）が Google のアカウントの情報をどう扱うかを説明します。

1. 使う人

本ツールは、YouTube チャンネル「そらゆめ さとがえり【古民家DIY】」の運営者本人だけが、自分のアカウントで使う個人用のツールです。ほかの人に提供していません。

2. 読み取る情報

  • YouTube：自分のチャンネルの動画の情報、コメント、再生数などの数字（YouTube Data API・YouTube Analytics API）。
  • Gmail：自分の受信したメールと、返信の下書き（Gmail API）。

3. 使い方

読み取った情報は、運営者本人がコメントやメールに返信すること、チャンネルの数字を記録することだけに使います。広告、販売、第三者への提供には使いません。

4. 保存

ログインの情報と読み取った情報は、運営者本人のパソコンと自宅の記憶装置にだけ保存します。外部のサーバーには送りません（返信の文を作るために、運営者本人が契約している AI のサービスに内容を渡すことがあります）。

5. 第三者への提供

法令で求められた場合を除き、第三者に提供しません。

6. アクセスの取り消し

Google アカウントの「サードパーティのアプリとサービス」（myaccount.google.com/connections）から、いつでもアクセスを取り消せます。

7. Google API の利用について

本ツールが Google API から受け取った情報の使い方と他のアプリへの受け渡しは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
